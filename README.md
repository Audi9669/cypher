Cypher tool 

It is a tool that is meant you to either encrypt or decrypt your text message using different methods 


Methods used: 

- Reverse Cipher: It is a tool that will reverse the string entered by user. ex input is a outcome will z 
- ROT13 Cipher: It s a tool that will show the input after being moved 13 steps. 
- Morse Code: It is a tool that takes an input and changes it to or from Morse Cod. 





How does it work?
- Get input ( from user ) 
- Decide what task to perform (Encrypt or Decrypt) 
- Choose the method ( Reverse, rot13, morse)
- return the ciphered value to user


how to run? 
- run cyphertool.go
- choose from the prompts printed on the screen
